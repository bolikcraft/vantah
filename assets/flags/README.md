# Флаги стран

PNG в `src/Vantah.App/Assets/flags/` собираются из набора
[flag-icons](https://github.com/lipis/flag-icons) (вариант 4x3, MIT — копия лицензии
лежит рядом: `LICENSE.flag-icons`). Имя файла — код из вывода `adguardvpn-cli`
в нижнем регистре: по нему флаг и ищется (`LocationItemViewModel`).

Перегенерация — вручную, результат коммитится:

```sh
./render.sh                    # склонирует набор во временный каталог
./render.sh ~/src/flag-icons   # или возьмёт уже скачанную копию
```

Нужны `inkscape` и `git`. Скрипт не запускается из сборки: она должна оставаться
воспроизводимой без сети и сторонних утилит.
